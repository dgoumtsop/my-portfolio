Featured project

Drift

An API gateway I built from scratch in Go. Its token-bucket rate limiter runs as an atomic Redis Lua script, so replicas can't race each other. If Redis dies it fails open to in-memory buckets, and it streams live metrics to a dashboard over SSE. It holds sub-100ms latency at 1,000+ concurrent requests. Go ahead, try to get rate-limited.

Go · Redis · Lua · Prometheus · Docker · k6

Featured project

Soccer Predictor

A Premier League match predictor built on a Dixon-Coles model and validated with walk-forward backtesting. I vectorized the likelihood fit with NumPy, so a full 380-match season fits in about 0.07s. Every prediction the API serves goes into a hash-chained ledger, so the model's track record can't be quietly rewritten.

Python · FastAPI · NumPy · SciPy · LightGBM · DuckDB
